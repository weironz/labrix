# Labrix

面向 GPU 数据中心的基础设施实验与验证工作台。

Labrix 的设计目标是把设备、端口、线缆、Ethernet / InfiniBand 网络平面、配置和实验结果连接起来，通过不同后端分别完成拓扑检查、真实网络操作系统仿真、配置分析及硬件测试结果对照。

**当前状态：调研和架构设计阶段，尚无可运行的软件实现。**

推荐方向是 **Rust 领域核心 + GPUI Kit 原生桌面 + Linux Rust Agent + Containerlab 等外部后端**。Rust 覆盖 Labrix 自有应用代码；外部 NOS、QEMU、Batfish、IB 工具和系统依赖各自保留原有技术栈。

## 项目原则

- 同一拓扑支持不同验证深度，每个结论记录后端、版本和证据。
- 真实 NOS 的配置验证、数学模型的性能估算、硬件测试分别表达。
- 物理端口、光模块笼、breakout 子端口和软件接口分别建模。
- 对不支持或未验证的能力明确报告，避免把缺失证据当成通过。
- 公开示例使用合成数据；生产配置、设备镜像、许可证及凭据不进入仓库。

本仓库首批交付物是原创调研文档，未复制第三方项目实现，也未打包厂商设备镜像。当前仓库尚未声明软件许可证；实现阶段需确定项目许可证及第三方 NOTICE。
